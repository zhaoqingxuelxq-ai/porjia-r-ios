13  云服务（配置同步 / 权限检查 / 会话恢复）
--------------------------------------------------------------------------------

  13.1 配置对象 minis.v9config/1
       schema / id / rev / updatedAt / device / payload / sig
       payload: toolVersion、initialHash、initialBytes、initialChars、
                marks、marksCount、bundleSize、bundleHash、chain、vars

  13.2 完整性
       签名 = HMAC-SHA256(token, canonical(cfg 去掉 sig))
       canonical 必须键序稳定，否则同样的内容算出不同签名。
       校验不通过就拒收，不做"内容看着像就收下"。

  13.3 通道
       本地目录（默认）：写 <dir>/<id>.json 与 latest.json，先写 .tmp 再 rename。
       HTTP(S)：PUT/GET，Authorization: Bearer <token>，15 秒超时。
       写失败不丢内容：入 outbox，下次 sync flush 重投。

  13.4 冲突
       不做整块覆盖。逐字段比较，策略 local / remote / newest。
       每个冲突字段都进 decisions 列表 —— 合并不留暗账。
       rev 取双方最大值 +1，不用时间戳当版本号。

  13.5 权限检查
       token 存在 → 过期时间 → scope。
       JWT 只读 claims 不验签（没有签发方密钥）；真正的完整性靠 13.2 的 HMAC。
       所以 token 泄露 = 内容可伪造，这一点写进文档，不假装安全。

  13.6 会话恢复 minis.v9session/1
       快照内嵌最初全文（base64）+ 哈希 + 补丁标记 + 注入链。
       恢复前必须：快照自身哈希对得上 → 才落盘 → 落盘后读回再比对。
       补丁状态只报告不修改：恢复不是打补丁，越界改 bundle 会让"恢复"变成二次打补丁。
       包被删、补丁被打回原版，都能靠快照把最初恢复回来。
