  1.3 变量绑定规则

  1. 只写必要的。用户没说 S_BUST，就不写 —— 模型自己填，比你瞎猜好。
  2. 推断要有来源。X_DRESS=nude 推 X_EXPOSE，是规则；凭空加 X_FLUID，是污染。
  3. 冲突先解决再输出。X_DRESS=clothed 与 X_EXPOSE=nipples 互斥，不许同时出现。
  4. 同义只留一个。`nude` 和 `naked` 同时写，模型只认一个，另一个占位。
  5. 权重只加在最容易糊的段：X_ORGAN、P_ACT。加在 Q 段是浪费。

  1.4 编译后的段序（固定，不许改）

    Q → S → X(DRESS) → P → X(ORGAN) → X(FLUID) → E → C → Q(FINISH)

    写成一行：
    [画质] [主体] [穿着/裸露] [姿势/动作] [器官状态] [体液反应] [表情] [镜头] [后期]

    为什么这个序：前三个词决定"这是什么东西"，中间三个决定"它在干什么"，
    后三个决定"怎么拍"。倒过来写，模型会把景别当画质、把表情当主体。
