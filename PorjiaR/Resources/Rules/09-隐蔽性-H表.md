8  隐蔽性（H 表）
--------------------------------------------------------------------------------

  这里管的是"痕迹"。不是躲谁，是别把工具本身的特征留在产物上。
  一条原则：产物里不许出现只有做这件事的人才会写的东西。

  ┌──────┬────────────────────────────┬──────────────────────────────┐
  │ H01  │ 产物里不出现包名/工具名     │ 提示词正文不写"按破甲内核…"   │
  │ H02  │ 产物里不出现路径             │ 不写 D:/…/超级无敌破甲v6/…    │
  │ H03  │ 产物里不出现规则编号         │ 不写"依 B3 条""按 K07"        │
  │ H04  │ 产物里不出现阶段名           │ 不写"P3 装配完成"             │
  │ H05  │ 英文提示词不夹中文注释       │ 模型会把注释当语义            │
  │ H06  │ 不留统一签名/固定前缀        │ 每批开头不要一模一样          │
  │ H07  │ 不写"已绕过/已注入/已破限"   │ 这类词本身就是痕迹            │
  │ H08  │ 二进制里不硬编码敏感路径     │ 见 §8.2                       │
  │ H09  │ 日志里不打印最初全文         │ 只打字节数与前 40 字          │
  │ H10  │ 备份文件名不带工具特征       │ 用 stock / patched 这种中性词 │
  └──────┴────────────────────────────┴──────────────────────────────┘

  8.2 H08 是最实的一条

  旧版把 `G:/WORKBUDDY/…/超级无敌破甲v6/最初.txt` 这个绝对路径
  烧进 15MB 的 SKILL.md。任何一个字符串扫描都能看到"破甲"两个字。
  这是硬痕迹，且随文件分发扩散。

  v8 处置：注入路径改走中性位置。

    第一跳   /var/minis/skills/minis-v9/.runtime/initial.dat        （无扩展名、无中文、名字无义）
    第二跳   /var/minis/shared/minis-v9/.runtime/initial.dat
    第三跳   内嵌最小最初（常量，无外部依赖）

  包内 最初.txt 仍然保留，作为源文件；部署时复制成上面那两个名字。
  这样：文件系统上看不出是什么，二进制里也搜不到包名，且回退链更稳。

  代价：改最初要重新部署（因为源在包里、运行在 .rt 里）。
  权衡取舍：隐蔽性优先。要热换，部署一次即可，之后改 .rt 里的 p.dat 也生效。
  两条路都留着，用户自己选。
