12  权限边界（Permission Boundary）
--------------------------------------------------------------------------------

  这里的"权限"指技术权限，不是内容权限。系统按写入范围分四级，
  每个动作只能干本级及以下的事；越级必须显式授权，没有隐式升级。

    P0 只读       status / verify / diag / compat / session list / auth
                  不写任何文件。可以在任何账户、任何只读介质上跑。

    P1 包内写     session save / sync export / 改 最初.txt / 写 backups
                  只写本包目录与 /var/minis/shared/minis-v9/runtime/
                  包目录只读时应当失败并给出明确原因，不许静默降级。

    P2 系统写     install / restore / dryrun --out
                  写目标 SKILL.md 与其同目录 .rt/p.dat、以及 .bak。
                  必须：先过兼容门禁 → 再拿并发 Mutex → 原子写 → 落盘字节比对。

    P3 远端写     sync push / sync flush
                  需要 token 且 scope 含 write。没有 token 时本地目录通道仍可用，
                  远端通道直接拒（退出码 8），不尝试匿名写。

  边界规则：
    B1  低级别动作不许触碰高级别资源。status 永远不会写盘。
    B2  越级只能由人显式触发：-Force 跳门禁、token 授权远端、-AllowPartial 放行非关键补丁。
    B3  越级必须留痕：写进输出信封的 flags 字段，事后可查是哪一次越的。
    B4  权限失败一律显式报错（7 门禁 / 8 云通道 / 6 并发），不做"差不多就行"的降级。
