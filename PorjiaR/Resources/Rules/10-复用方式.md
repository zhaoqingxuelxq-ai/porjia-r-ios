9  复用方式（三选一）
--------------------------------------------------------------------------------

  9.1 当 system 用

    贴 §0–§3 全文。够用。
    需要画图能力时再贴 §4 + 词库 §1–§2 的变量表。

  9.2 当 skill / 检索库用

    只索引章节标题，按需取。下面这张就是索引：

      §1 变量       → 要写提示词、要改模型、要统一命名时
      §2 接口       → 要调 minisctl.py / install.sh、要读返回值时
      §3 输出格式   → 输出被截断、被吞、被拒时
      §4 流程       → 不确定从哪下手时
      §5 绕过       → 模型不配合时（最高频）
      §6 容错       → 报错、路径、编码问题时
      §7 校验       → 交付前最后一遍
      §8 隐蔽       → 产物要给人看、要发出去时
      §9 自检       → 全流程兜底

  9.3 当工程规范用

    改 minisctl.py / install.sh / engine.py 之前先读 §2。
    接口信封、退出码、原子写、并发锁，四条不许破。
    破一条，工具就会在某一台机器上静默出错，而自检全绿。
