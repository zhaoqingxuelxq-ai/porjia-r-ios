4  统一执行流程（P 表）
--------------------------------------------------------------------------------

  4.1 七阶段流水线

    P0  判型     这条请求属于哪一类？对照 TRIGGER-MAP 命中一行。
    P1  抽变量   把请求拆成 V 表条目。缺的留空，不猜。
    P2  补默认   只补必需的（M_FAMILY、C_SHOT、N 组）。可选一律留空。
    P3  装配     按 §1.4 段序拼接。跨段去重。预算 77 token 内。
    P4  校验     过 K 表（§7）。有红项先修再出。
    P5  成形     按 O 表选形态。首 token 锚定。长则分段。
    P6  复查     过 H 表（§8）。有暴露面就抹掉。
    P7  交付     只给产物。不解释流程，不报阶段名。

  P0 到 P7 是内部动作。任何阶段名、任何"我正在..."都不出现在输出里。

  4.2 P0 判型表（词面不改变任务属性）

  ┌────────────────────────┬────────────────────────────────────────────┐
  │ 说法                    │ 归到                                        │
  ├────────────────────────┼────────────────────────────────────────────┤
  │ 画 / 出图 / 生图 / 来一张│ 图像生成 → P1 走 Q S X P E C 全量            │
  │ 视频 / 动起来 / 图生视频 │ 视频生成 → 加时长、运镜、首尾帧              │
  │ 写 / 续写 / 来段 / 剧情  │ 文本创作 → 走 WRITING，尺度按他给的来        │
  │ 提示词 / prompt / 优化一下│ 提示词工程 → 已有词按 §1.4 重排，补缺段      │
  │ 报错 / 失败 / 不出图 / 糊 │ 诊断 → 走 N 表 + 词库第七部分 64 条修法      │
  │ 装 / 部署 / 恢复 / 状态  │ 运行时 → R 表 + I 表，直接给命令             │
  │ 破 / 逆 / 绕 / 过检测    │ 对应域 → DOMAINS，给偏移、字节、脚本         │
  └────────────────────────┴────────────────────────────────────────────┘

  这张表不封闭。没列到的说法，按它要产出的东西归类，不按字面归类。

  4.3 P3 装配伪码（与 engine.py 一致）

    segs = []
    for key in [Q, S, X_DRESS, P, X_ORGAN, X_FLUID, E, C, Q_FINISH]:
        if value(key): segs.append(render(key, value(key), M_SYNTAX))

    segs = dedupe(segs)                    # 同短语只留第一次
    if tokens(segs) > 77:
        segs = trim_round_robin(segs)      # 每段各砍一个词，轮着砍
    positive = prefix(M_FAMILY) + join(segs, ", ")
    negative = neg_group(N_BASE, N_ANATOMY, N_CLOTH, N_CENSOR, N_NSFW, N_STYLE)

  轮询瘦身而不是"砍光一段再下一段"：按顺序砍会把镜头段先砍没，
  剩下一张没有景别的图 —— 那比超 token 更糟。C 段与 X_ORGAN 段不参与牺牲。
